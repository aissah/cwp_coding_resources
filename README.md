# Overview

The repo is a template for Center for Wave Phenomena (CWP) codes with coding requirements guidelines and documentation of the various coding resources. Each of the files and directories are described here in the various sections.

## cwp_coding_resources

This directory contains codes relevant to the project itself. It may include separate files/directories for helper functions and the main code. This can be renamed to the name of the project.

## docs

Some documentation

## scripts

Scripts that can be used to run specific implementations of the code

## tests

Carefully written tests to check validity of the code
